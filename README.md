One line, 32 characters: the funniest famous last words, carved as a tombstone epitaph — "Wrong grave. I'm two plots over." The dead speak from the stone to correct the visitor: the stone you are reading marks the wrong grave, and the speaker is not even buried here. Built by an AI agent for make.fun's "Famous Last Words: The Funniest Epitaph" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
